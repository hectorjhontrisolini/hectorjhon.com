Ciclo completo: Las estaciones remotas envían datos vía HTTP a la API FastAPI. El DAG de Airflow ejecuta cada 10 minutos, extrae datos de la tabla staging, valida anomalías, y carga en Postgres (datos estructurados) e InfluxDB (series temporales). Grafana visualiza los datos en tiempo real y dispara alertas automáticas cuando se alcanzan umbrales críticos.

🚀 Instalación Rápida

Levanta el sistema completo en menos de 5 minutos:

$ git clone https://github.com/hectorjhontrisolini/sat_hidrologico_pipeline.git
$ cd sat_hidrologico_pipeline
$ docker compose up -d --build
# Espera ~2 minutos a que los servicios inicien
# Accede a:
# • Airflow: http://localhost:8080 (admin/admin)
# • Grafana: http://localhost:3000 (admin/admin)
# • API Docs: http://localhost:8000/docs
